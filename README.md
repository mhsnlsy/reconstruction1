# reconstruction1 — Theodosius Obelisk

İstanbul Sultanahmet Meydanı'ndaki Theodosius Dikilitaşı'nın 390 CE civarında yeniden dikilişini kısa bir görsel rekonstrüksiyonla anlatır.

## Demo

Kök dizindeki `index.html` doğrudan çalışır. GitHub Pages için `.github/workflows/pages.yml` ile otomatik yayınlama yapılandırılmıştır.

## Animasyon

- Süre: **12 saniye** (1.0×)
- Varsayılan hız: **0.95×**
- Kullanıcı hız aralığı: 0.50×–1.50×
- Tek sürekli kaldırma: yataydan dik konuma
- Halat + makara + ahşap kaldırma düzeneği
- Mobil uyumlu
- Harici JavaScript kütüphanesi gerektirmez

## Tarihsel çerçeve

Theodosius Dikilitaşı'nın kaidesindeki kuzey yüz kabartması, dikilitaşın kaldırılma sahnesini gösterir. Antik mekanizmanın bütün ayrıntıları kesin olarak bilinmediği için bu proje, kabartmanın görsel ipuçlarını ve antik kaldırma tekniklerini temel alan **basitleştirilmiş bir rekonstrüksiyon** sunar.

Kaidedeki yazıtlar süre konusunda farklıdır: Latin metin 30 gün, Yunanca metin 32 gün bildirir. Bu nedenle animasyondaki 12 saniye gerçek zaman ölçeği değil, görsel anlatım süresidir.
